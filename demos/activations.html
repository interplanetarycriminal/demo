Activation Functions

Space play · ←/→ tour · R reset

An activation is the bend between layers: without it a deep net is one straight line, and its slope f′ decides whether learning signal survives the trip back through depth.

    In the wild

    • GELU runs inside every GPT-2, BERT and ViT block; SiLU is the gate in SwiGLU, the feed-forward layer of Llama, Mistral and PaLM.
    • ReLU is still the default in CNNs and ResNets for vision: cheap, and a slope of exactly 1 keeps gradients alive.
    • Sigmoid and tanh moved out of hidden layers into gates (LSTM/GRU, attention gating) and outputs (probabilities); softplus keeps things positive, e.g. variances and Mamba's step size Δ.

    The function under the probe

    ReLU: f(x) = max(0, x)
    f′(x) = 1 if x > 0 else 0
    at x = 0: f = 0, f′ = 0

    Stacked linear layers collapse

    W₃(W₂(W₁x + b₁) + b₂) + b₃ = W′x + b′

    Any number of linear layers equals one. Only the nonlinearity f between them lets depth add new bends (the net panel).

    Backprop multiplies by f′ at every layer

    δk = (Wk+1ᵀ δk+1) ⊙ f′(zk)
    ‖δ₁‖ ≈ Πk (weight gain × mean f′)
    here: mean f′ = 0 over 12 layers
    → ‖δ₁‖ = 0
    σ′(x) = σ(x)(1 − σ(x)) ≤ 0.25
    ⇒ best case 0.2512 = 0

    Weights start as W ~ N(0, g²/n): g² = 1 (Xavier) for sigmoid/tanh, g² = 2 (He) for the ReLU family, times the weight scale slider. Same random draws for every function, so the race is fair.

    Misconception: "ReLU solved vanishing gradients." It removed the activation's shrinkage (f′ = 1). The weights still multiply in: at 0.7× init a 30-layer ReLU net vanishes, at 1.5× it explodes. Init, normalization and residual connections do the rest.

    Why a dead ReLU never recovers

    ∂L/∂b = meann 2(f(zn) − yn) · f′(zn) = 0  if zn < 0 for every input n
    Leaky ReLU keeps f′ = 0.1 there (PyTorch default 0.01), so the bias still gets pushed back up. GELU and SiLU keep f′ > 0 just below 0 (down to their dips at −0.75 and −1.28), so neurons pushed a little negative recover. Past the dip f′ turns negative and fades to 0, so in this lab they slide further down and can die too.
