Diffusion Models

Space play · ←/→ tour · R reset

A diffusion model learns one skill — look at a noisy point and guess the noise in it — and generates data by applying that guess again and again, starting from pure static.

    In the wild

    • Stable Diffusion, Imagen, DALL·E 3, Midjourney: this exact loop runs in the compressed latent of an image, with a U-Net or transformer predicting ε̂ from the noisy latent, t and the text prompt, and guidance w around 5–8.
    • Video, audio, molecules: video models diffuse spacetime patches; AlphaFold 3 and RFdiffusion diffuse 3-D atom coordinates, literally point clouds like this one.
    • Fast samplers: DDIM, DPM-Solver and distilled / consistency models are all about the steps slider: fewer network calls per image at the same quality.

    1 · Forward: trade signal for noise

    xt = √ᾱt·x0 + √(1−ᾱt)·ε,  ε ~ N(0, I)
        = 1·x0 + 0·ε

    ᾱt = ∏s≤t(1 − βs) is the schedule plot. Signal-to-noise SNR = ᾱ/(1−ᾱ) = –. Because the two coefficients square-sum to 1, Var[xt] = ᾱ·Var[x0] + (1−ᾱ): it glides from the data’s variance (≈ 0.74 per axis here) to exactly 1 and never blows up. Measured now –.

    2 · The model: predict the noise

    loss = ‖ε − ε̂θ(xt, t)‖²
    ⇒ best ε̂ = E[ε | xt]
    x̂0 = m + (√ᾱσ₀²/v)(xt − √ᾱ m)
    m = Σk wk xk,  v = ᾱσ₀² + 1 − ᾱ
    wk ∝ exp(−‖xt − √ᾱ xk‖² / 2v)
    ε̂ = (xt − √ᾱ x̂0) / √(1−ᾱ)
      = −√(1−ᾱ)·∇log pt(xt)

    This demo uses the exact minimiser for a training set of K points (each blurred by σ₀), so no network is needed. Probe: ‖ε̂‖ = –, largest vote wmax = –.

    3 · Reverse step (DDPM and DDIM are one formula)

    xt′ = √ᾱt′·x̂0
      + √(1−ᾱt′−σ²)·ε̂ + σ·z
    σ = η·√((1−ᾱt′)/(1−ᾱt))
      ·√(1−ᾱt/ᾱt′)
    η = 1: DDPM  ·  η = 0: DDIM
    now t → t′ = –
    σ = –

    4 · Classifier-free guidance

    ε̃ = ε̂(x | c)
      + w·(ε̂(x | c) − ε̂(x))
    w = 0
    Misconception: “the reverse process replays the added noise backwards.” It never sees that noise, only xt and t. Starting from the same xT, a sample ends wherever the learned flow takes it (Try this #1).
    Misconception: “a better denoiser is always a better generator.” The exact ε̂ here is the best possible on its training set, and with few points it only copies them (Try this #3). Real networks generalise because they approximate.
