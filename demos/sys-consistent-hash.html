CONSISTENT HASHING

Hash servers and keys onto one ring; a key belongs to the next server clockwise — so a new server steals only the arc behind it.

Honesty: hash = 32-bit FNV-1a over label strings, so positions are deterministic but not cryptographic; real rings hash 128-bit MD5/Murmur and store replicas on the next R distinct servers.
Lineage. Karger et al. 1997 invented consistent hashing for web caching — relocating clients without a global rehash. Amazon Dynamo (2007) put it under a database, adding virtual nodes for load smoothing. Today it is memcached clients, Cassandra and Riak token rings, and every CDN deciding which edge holds your object.
