Word Embeddings

Space play · ←/→ tour · R reset

A word embedding turns each word into a list of numbers, so that similar meanings point in similar directions and relations become arrows you can add.

    In the wild

    • Every LLM starts with an embedding table: token id → row of learned numbers (thousands of them), and many reuse the same table to score the next token.
    • Semantic search and RAG embed the query and every document, then return the top matches by cosine: the ranking card, at scale.
    • Recommenders put users and items in one space; "more like this" is a nearest-neighbour lookup.
