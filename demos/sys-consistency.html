Honesty: a 3-to-5 replica toy with one key and per-key versions — no transactions, no clock skew, no read repair, and "strong" here means quorum overlap, not linearizability with real clocks.
Lineage. Terry et al. (Bayou, 1994) named the session guarantees — read-your-writes, monotonic reads, writes-follow-reads. Dynamo (2007) shipped tunable N/R/W quorums so an operator could dial the trade per request. Today every cloud database has a consistency page — Cosmos DB sells exactly five levels, bounded staleness included.
