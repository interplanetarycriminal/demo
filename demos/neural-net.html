Neural Playground

Space play · ←/→ tour · R reset

Every neuron draws one soft straight line across the plane; stacking layers of them lets a network combine those lines into any shape the data needs.

    In the wild

    • Inside every LLM. Each transformer block has an MLP exactly like this one (just thousands of times wider, with GELU or SwiGLU), trained by the same backprop loop.
    • Recommenders and ads. Ranking models feed user and item embeddings into small MLPs that output a click probability, the same σ output as here.
    • Game-playing and robotics. AlphaZero's policy/value heads and many robot controllers are MLPs mapping a state to a score or an action.

    1 · Forward pass

    Each hidden layer takes a weighted sum of the layer below and squashes it with the activation φ = tanh. The output is a probability.

    h⁽⁰⁾ = (x₁, x₂)
    h⁽ˡ⁾ = φ( W⁽ˡ⁾ h⁽ˡ⁻¹⁾ + b⁽ˡ⁾ )
    p = σ( wₒ · h⁽ᴸ⁾ + bₒ ) = P(A)

    3 · Loss: cross-entropy + L2 penalty

    L = −mean[ y log p + (1−y) log(1−p) ]
      + λ/2 · Σ w²
      = – + –   (λ = 0)

    4 · Update: gradient descent with momentum

    v ← 0.9·v − η ∂L/∂w
    w ← w + v   (η = 0.03)

    Every step uses all training points (one step = one epoch). Backprop computes every ∂L/∂w with one backward sweep of the chain rule, through tanh′ at each layer.

    Misconception: "the network draws curves". A layer-1 neuron can only draw one straight line. Curves appear because the next layer adds many soft steps together; with ReLU the result is literally a polygon.
    Misconception: "lower training loss = better model". Watch the dashed test loss. When it rises while training loss falls, the network is memorising noise. L2 (λ) and fewer neurons trade training fit for generalisation.
