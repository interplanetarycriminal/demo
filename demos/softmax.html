Softmax & Sampling

Space play · ←/→ tour · R reset

A language model never outputs a word. It outputs a score for every word; softmax turns the scores into odds, and the decoding knobs decide how boldly it rolls the dice.

    In the wild

    • Every LLM API exposes temperature and top_p; open models ship a generation config with top-k / top-p defaults. This pipeline runs once per generated token.
    • The same softmax turns scores into weights inside every attention head, and ends almost every classifier.
    • Knowledge distillation raises T so a student can learn from a teacher’s tail probabilities, and RL agents explore with softmax (Boltzmann) policies.

    1 · Softmax with temperature

    pi = ezi/T ⁄ Σj ezj/T
    p(mat) = e3.20/1.00 ⁄ Σ
            = 24.5 ⁄ 58 = 0.420

    Follows the token you hover or drag (else the top one). Columns: coral positive and teal negative logits, grey exp, blue probability.

    2 · Cut the tail, then renormalise

    top-k: keep the k largest pi  · k = off
    top-p: smallest S, ΣS pi ≥ p = off
    → |S| = 10, mass 1.000
    qi = pi ⁄ Σkept pj
    kept 10 → q = 0.420

    3 · How spread out is the choice?

    H = −Σ qi log₂ qi = 2.1 bits
    effective choices = 2H = 4.3
    Misconception: “temperature changes which word is most likely.” It never does. Dividing by any T > 0 keeps the order; T only changes how far apart the probabilities are. And adding the same number to every logit changes nothing at all.
    Order matters: temperature is applied before top-p, so a hot T grows the nucleus. Here top-k and top-p both read the same temperature-scaled p. Hugging Face applies top-p after top-k has renormalised, which can trim slightly more.
    Sampling is inverse-CDF: draw u ~ U[0,1) and pick the token whose slice of the dice strip contains u. After N rolls, the histogram’s gap (half the L1 distance) shrinks like 1/√N.
