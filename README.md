# demo

### ▶ Live visual demo gallery: **https://interplanetarycriminal.github.io/demo/**

117 interactive WebGL, Canvas, Three.js, p5.js, D3, GSAP and Matter.js demos — raymarched
fractals, an 80k-star particle galaxy, GPU reaction–diffusion, a black hole, strange
attractors, playable neon arcade games and more. The source lives in [`demos/`](demos/);
see [`demos/README.md`](demos/README.md) for the full list and how to run it locally.

The site is published to GitHub Pages from `main` by
[`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml), which serves the
`demos/` folder as the site root.

This repository also contains the original Astro “Hinze Pond fish-monitoring” proof-of-concept
under [`src/`](src/).
